# QRama

Generador de códigos QR gratuito que funciona completamente en el navegador.

## Funciones

- Códigos QR para enlaces, texto y redes Wi-Fi.
- Personalización de colores, tamaño y corrección de errores.
- Descarga en PNG o SVG y copia directa al portapapeles.
- Diseño responsive y accesible.

## Desarrollo

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```
